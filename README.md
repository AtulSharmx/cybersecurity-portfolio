# Cybersecurity Portfolio

Hands-on work I am building while training for a SOC (Security Operations Center) Analyst role. Everything here is practice work, and each folder will get its own README explaining what I did and what I learned.

## Structure

- `python-scripts/` - small Python security tools (for example the SSH log parser: https://github.com/AtulSharmx/log-parser)
- `log-analysis/` - reading and investigating real log files
- `phishing-analysis/` - breaking down phishing emails (headers, links, attachments)
- `letsdefend-investigations/` - write-ups of investigations from LetsDefend / CyberDefenders
- `siem-detection/` - detection rules and searches in a SIEM (Splunk free tier)
- `ir-playbooks/` - simple incident response playbooks

## Status

This repo is new. Folders are added only when there is real work to show, and each write-up follows the same pattern: what I saw, what I concluded, and what I would do next.
